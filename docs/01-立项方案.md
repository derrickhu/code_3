## 1. 一句话

> 宋江被押上江州法场，官兵一波接一波地压过来。你手里只有几块炊饼，拿去招好汉。  
> **抽到一个「武」字先别急，等「松」字落在它右边，金框一亮，整条路的官兵被一刀清空。**

### 1.1 为什么做这个

| 事实 | 对我们意味着什么 |
|---|---|
| 《赵云与阿斗》上线两周拿下抖音小游戏热门榜、新游榜第一，随后登顶抖音畅销榜；微信畅玩榜、人气榜、PC 榜同时霸榜；抖音话题播放公开报道 2 亿–7 亿 | 「文字塔防」已被验证为 2026 年小游戏最大黑马品类，用户教育已经完成 |
| 核心团队 3–5 人、纯 IAA、无重度内购、视觉极简（汉字 + 水墨） | 与我们团队规模、已有的水墨塔防工程（black-rosa）高度匹配，研发成本可控 |
| 蜜獾自己用同框架换西游题材做了《悟空与唐僧》（8 月），抖音新游榜连霸 6 天，但整体热度与商业表现不及前作 | **纯换皮能吃到品类红利，但会弱于原作**。要做到「爽感不弱于」，题材必须带来机制上的新爽点，而不只是换字 |
| 三国、西游、水浒都是公共领域文化符号，零授权成本 | 水浒 108 将是三大名著里人物最多、绰号最响、名场面最「打」的，天然适合「收集 + 组字 + 大招」 |

### 1.2 为什么是水浒、为什么是「营救宋江」

- **结构天然对位**：原作是「赵云护阿斗」，水浒里宋江是全书被救次数最多的人——清风寨被刘高擒、江州劫法场、还道村被追捕躲进玄女庙。「营救宋江」不需要编故事，原著就是关卡表。
- **名字天然是字谜**：水浒好汉同姓扎堆（三个张、三个阮、两个解、两个孙），「这个张字给张顺还是张清」是三国题材没有的抢字决策（§5.3）。
- **绰号与名场面天然是技能**：武松打虎、鲁智深倒拔垂杨柳、花荣射雁、时迁盗甲、戴宗神行、吴用智取——每个都能一句话说清它在战场上干什么。
- **梗天然能传播**：「炊饼」当货币、「及时雨」当卖血补偿、「武大郎」是隐藏好汉——玩家会自己去发视频。

## 2. 体验目标（设计北极星）

### 2.1 主体验

> 当刷短视频的玩家在碎片时间开一局时，反复感到：**「下一个字一定是它」的赌，和「名字拼齐那一下」的炸。**  
> 爽来自我自己摆的格子、我自己赌的那张牌，而不是自动战斗的数字。

**核心动词：抽、摆、合、拼。** 抽 = 聚义开盲盒；摆 = 有限格子排兵布阵；合 = 同字同级合成；拼 = 凑齐姓名召唤好汉。

### 2.2 必须可检验的四点（与原作同标准）

1. **每次聚义都是赌**：点下按钮到字牌落地那 0.5 秒，玩家在心里喊一个字。
2. **格子永远不够**：战场空位 + 5 格山寨，始终逼玩家做取舍（留字等名字 vs 先合成保命）。
3. **名字拼齐有质变**：好汉激活前后，防线强度肉眼可见地跳一档，伴随全屏演出。
4. **对面在看着**：上半区对手的阵型、血量、好汉实时可见，「他拼出来了我还没」的压迫感一直在。

### 2.3 玩家应该脱口而出

- 「松呢？我要的松呢！」
- 「三个阮凑齐了，水上直接清屏」
- 「宋江掉血了，及时雨来了，爆兵反推！」
- 「为什么武大郎能上，西门庆不能上」

### 2.4 反目标（出现即失败）

| 玩家感受 | 诱因（设计上要挡） |
|---|---|
| 「就是赵云与阿斗换了个皮」 | 只换字不换机制；没有同姓抢字、名场面克制、及时雨这些水浒原生爽点 |
| 「抽了十个字一个名字都拼不出」 | 好汉字牌掉率、池子大小失控；没有保底 |
| 「好汉拼出来也没啥变化」 | 激活演出弱、数值跳档不够 |
| 「不看广告打不过」 | 广告成为通关前置条件 |
| 「卡、掉帧、加载半天」 | 引擎首包过大、敌兵同屏数量没做池化（§11） |

## 3. 对标拆解：《赵云与阿斗》到底怎么玩

以下来自录屏逐帧观察（关卡「巨鹿」第 6–9 波，含一次失败结算）与公开报道交叉核对。**标「录屏」的是亲眼所见，标「报道」的是二手信息。**

### 3.1 画面布局（录屏）

```
┌──────────────────────────────┐
│ 暂停  馒头数    关卡名·第N波   │  顶栏
├──────────────────────────────┤
│ 斗♥♥♥ ……对手半区……  敌人出口  │  上半区：对手的阿斗、兵、好汉
│      格子（草地）+ 路径        │
│ ─ ─ ─ ─ 中线 ─ ─ ─ ─ ─ ─ ─    │
│ 敌人出口 ……我方半区…… ♥♥♥斗  │  下半区：我方
├──────────────────────────────┤
│ [营] □ □ □ □ □               │  兵营 5 格（待部署字牌）
│        [ 征兵 🍞18 ]           │  征兵按钮，显示当前价格
└──────────────────────────────┘
```

- 竖屏，战场约 8 列 × 10 行，上下两个半区**中心对称**：对手阿斗在左上、出口在右上；我方出口在左下、阿斗在右下。
- 路径是褐色石板，蜿蜒穿过草地；兵只能放在**草地格**，放上去后格子变白底；路径格不能放。
- 敌人是黑色「贼」字，头顶红色血条 + 血量数字，成串沿路径走向阿斗。
- 阿斗是一个「斗」字，戴小黄帽，旁边 3 颗心。敌人接近时阿斗旁出现红色「危」字；快不行时阿斗冒气泡「我快不行了」。

### 3.2 单位（录屏）

| 类 | 字 | 观察 |
|---|---|---|
| 基础兵种 | 刀、枪、弓、骑 | 白底黑字，右上角小数字 = 等级（录屏见到 1–3）。攻击时字形变形成兵器：「弓」拉成弓射箭，「枪」突刺，「刀」挥砍，「骑」冲锋 |
| 武将字牌 | 赵、平、苞、忠、张、飞…… | 金色字。单字时「睡大觉」无战力；**按姓名顺序相邻摆放**后合体，金框横跨两格（录屏 1:52「张」「飞」相邻合成「张飞」） |
| 敌人 | 贼 | 普通兵；另有戴面具的「人」精英（血量 54，远高于普通 4–20），出场前兵营右侧弹出橙色预警图标 |

### 3.3 核心循环（录屏 + 报道）

```
杀敌 → 掉馒头（每只 +1，录屏可见 "+1" 飘字）
  → 点「征兵」花馒头（价格递增：18 → 20 → 22 → 24，每次 +2）
  → 兵营 5 格刷出随机字牌：刀/枪/弓/骑（常见）、金色武将字（稀有）、铲子（稀有，扩一格地）
  → 拖到战场草地格部署；可从战场拖回兵营暂存
  → 同字同级拖到一起 = 合成升一级（攻击、攻速提升）
  → 武将字按姓名顺序相邻 = 激活武将（专属技能、大招）
  → 撑过一波，下一波敌人更多更厚，并随机出带技能的 Boss
```

### 3.4 原作的关键设计（报道）

| 机制 | 内容 | 作用 |
|---|---|---|
| 征兵递增 | 每次征兵价格上涨 | 控制节奏，前期爆兵快、后期每次抽都珍贵 |
| 卖血经济 | 阿斗受伤时系统瞬间补大量馒头 | 落后方有翻盘手段；玩家研究出「故意放兵掉血 → 爆兵反推」流派，成为传播梗 |
| 1V1 对称 | 双方条件完全一致，谁的阿斗先归零谁输 | 对抗感、实时比较 |
| 武器装备（局外） | 对局掉落武器，分品质；武将只能装对应武器（赵云枪、关羽刀、黄忠弓、刘备剑） | 局外养成 |
| 神秘商人（局外） | 每局结束随机出售道具，金币或看广告抽；不可刷新；道具仅当天有效 | 每日新鲜感 + 广告点，且不积累数值崩坏 |
| 道具携带 | 最多 2 主动 + 6 被动。被动如「陨石」（敌近阿斗时砸）、「淤泥」（减速）；主动如「神兵符」（兵升一级）、「砚台」（泼洒区域减速） | 对局变数、直播节目效果 |
| 军衔 | 「军士·一」+ 1–5 星；「从士兵到皇帝的军衔成长」 | 长线目标 |
| 结算 | 失败 / 胜利 + 军衔星 + 金币 ×N +「双倍金币」（广告）/「领取」 | 核心广告点 |
| 变现 | 纯 IAA：广告换体力、铲子、抽道具、更多金币；省 / 全国排行榜 | 无内购 |
| 原型 | 业内普遍认为是韩国 111% 的《Random Dice》本土化魔改：骰子换成汉字，加了组字召唤 | 玩法框架本身是品类通用的 |

### 3.5 原作的爽点清单（我们必须逐条不弱于）

| # | 原作爽点 | 来源 |
|---|---|---|
| S1 | 征兵开盲盒，刷出金字那一下 | 随机 + 稀有度 |
| S2 | 两个同字合成升级 | 合成即时反馈 |
| S3 | 凑齐姓名激活武将 | 字谜 + 质变 |
| S4 | 字变兵器的水墨攻击动画、墨汁伤害 | 视觉新鲜 |
| S5 | 卖血爆兵反推 | 翻盘 |
| S6 | 随机 Boss 冲击防线 | 紧张 |
| S7 | 盯着对手半区、用道具干扰对方 | 对抗 |

## 5. 核心玩法

### 5.0 规则层与原作完全相同

§3.3 的循环原样复刻：炊饼 → 聚义（递增价格）→ 随机字牌进山寨 → 拖到草地格 → 同字同级合成 → 按姓名顺序相邻激活好汉 → 守波次 → 宋江 3 颗心归零即负。上下对称 1V1，谁的宋江先倒谁输。

**本章以下内容是「在不改规则的前提下」，用水浒原生素材加厚爽点。** 每一条都标注它对应原作哪个爽点、是否改变规则。

### 5.1 兵种（S2、S4）

| 字 | 定位 | 攻击形态（字变兵器） | 初版参数方向 |
|---|---|---|---|
| 刀 | 近战高单体 | 「刀」字横劈成一道墨弧 | 射程 1 格，攻速中，伤害高 |
| 枪 | 直线穿透 | 「枪」字的木字旁拉长成枪杆突刺 | 射程 2 格直线，穿透 2 个 |
| 弓 | 远程单体 | 「弓」字弯成满弓射出墨箭 | 射程 3 格，攻速慢，伤害中 |
| 骑 | 高攻速 + 击退 | 「骑」字的马字旁化成奔马冲撞 | 射程 1.5 格，攻速快，小击退 |

- 等级上限建议 5 级（录屏只见到 1–3，P0 校准）。每级攻击 ×1.8、攻速 +10%。
- 等级用字右上角数字 + 字体由细到粗、墨色由淡到浓双重表达，一眼可读。

### 5.2 好汉召唤（S3）

- 好汉字牌是金字，单字无战力。**按姓名顺序在战场上横向（左→右）或纵向（上→下）相邻**，自动合体，金框覆盖所占格子。
- 两字名占 2 格，三字名占 3 格（必须一条直线）。三字名更难凑、格子占得更多，所以更强。
- 好汉自带专属技能 + 一个蓄能大招（击杀充能，满了自动释放，全屏演出 1 秒）。
- 好汉也能合成升级：两个同名同级好汉合成。

**首发好汉池（P1 16 人，P2 扩到 36 天罡）**

| 好汉 | 字数 | 技能方向 | 大招 |
|---|---|---|---|
| 武松 | 2 | 近战爆发，对「虎」类 Boss 伤害 ×5 | 醉打：连续 18 拳 |

### 5.3 水浒原生爽点一：同姓抢字（S3 加厚，规则不变）

水浒的名字天然共享字，于是「组字」从「凑齐」变成「抢」：

| 共享字 | 可组名字 | 玩家决策 |
|---|---|---|

### 5.5 水浒原生爽点三：及时雨（S5，规则相同、表现加强）

- 规则与原作卖血补馒头相同：宋江每掉一颗心，立刻补一大笔炊饼。
- 表现加强：宋江撒钱动画 + 全屏金雨 + 「及时雨来了！」大字 + 聚义按钮闪光，3 秒内聚义价格临时打 5 折（数值待校）。
- 目的：把原作玩家自发研究出来的「卖血流」做成**官方认证的名场面**，玩家更愿意录屏。

### 5.6 对手半区与干扰（S7）

- 对手占上半区，阵型、好汉、宋江血量实时可见。
- 干扰手段与原作结构相同：主动道具 + 少数好汉大招（时迁盗甲、吴用智取）可影响对手。
- **对手实现**：首版为 AI，按「玩家阵容快照 + 行为脚本」驱动，强度随座次匹配；显示「对手阵容来自某地玩家」，**不伪装成实时真人**（平台规范风险，§12）。P3 视数据再评估实时对战。

### 5.7 隐藏好汉与梗（S8）

## 8. 美术与表现

### 8.1 风格

- **汉字 + 水墨**，与原作同一大类，但要能一眼区分：
  - 原作：米白宣纸底 + 灰绿草地 + 黑字。
  - 本作：**泛黄古籍 + 青绿山水（梁山水泊）+ 朱红印章**。水格是本作专属地形，画面里要常见。
  - 关键识别符：好汉金字激活时盖一枚朱红「替天行道」小印；宋江是戴枷的「宋」字。
- UI 布局不照搬原作：山寨格、聚义按钮、顶栏的位置与造型重新设计（可参考 black-rosa 已有的 `InkTheme` 水墨 UI 体系）。

### 8.2 字形资源

| 类 | 数量 | 做法 |
|---|---|---|
| 基础兵种 4 字 × 5 级 | 20 个静态 + 4 套变形动画 | 美术手绘书法字，每套攻击动画 6–8 帧序列帧 |
| 敌兵字 | 每章 3–5 个 | 手绘 |
| 好汉字 | P1 约 40 字，P2 约 90 字，最终约 200 字 | 用**可商用开源字体**出字形（如霞鹜文楷，OFL 协议），统一描金、加墨迹后处理；不做逐字动画，攻击用统一的兵器墨迹特效 |
| 大招演出 | 每好汉 1 段，1 秒 | 一张精修水墨插画 + 镜头推拉 + 墨溅粒子 |

**字体版权是硬风险**：方正、汉仪等书法字体商用必须买授权，不能直接用系统里装的字体出图。

### 8.3 音效

- 字变兵器的墨迹声、合成「叮」、金字出现的锣声、好汉激活的鼓点、及时雨的铜钱雨声。
- 沿用仓库 `game-sfx-gen` 管线批量生成，压缩为小游戏规格 mp3。

## 9. 数值框架（方向，细节另起文档）

| 项 | 定 |
|---|---|
| 聚义价格 | 起价 10 炊饼，每次 +2（原作录屏为 +2 递增，起价我们自定） |

## 11. 引擎评估

### 11.1 候选对比

| 维度 | 团结引擎 2022.3.62t8 | Unity 国际版 2022.3 LTS | Cocos Creator 3.8 |
|---|---|---|---|
| 团队经验 | **已用它上线 black-rosa 微信小游戏**，转换流程、WX-WASM-SDK、云开发都跑通 | 与团结代码层完全兼容 | 需重学 TS + 引擎 |
| 微信小游戏 | 官方合作，转换工具内置 | 需外挂微信转换插件，可用 | 原生支持，最成熟 |
| 抖音小游戏 | 团结内置抖音平台转换 | 需额外接抖音 SDK | 原生支持 |
| 首屏启动 | 较慢：wasm + data 需要从 CDN 拉，低端机冷启动明显慢于 Cocos | 同左 | **最快**，包体最小 |
| 运行性能 | C# 编译为 wasm，计算性能好；同屏百级精灵没问题 | 同左 | JS，同屏大量单位时需更小心 |
| 可复用代码 | black-rosa 的水墨 UI、结算、体力、签到、引导、宝箱、奖励飞入、波次路径等 | 同左 | 无 |
| 风险 | iOS 高性能模式内存、首包下载 | 同左，且抖音链路需自行打通 | 团队切换成本 |

### 11.2 结论

**用团结引擎 `2022.3.62t8`**，即「Unity 的小游戏特化分支」，满足用户「用 Unity」的意向，同时直接继承 black-rosa 已跑通的双端出包链路。

本品类对引擎的压力不大（2D 精灵 + 序列帧 + 粒子，无物理、无 3D），团结的主要短板只有**启动速度**，用下面的手段压住：

| 风险 | 对策 |
|---|---|
| 首屏慢 | 首场景只放战斗必需资源；好汉字、大招插画、章节地图全部走 CDN 分包按需加载；启动页做「宋江被押上法场」的纯图片过场掩盖加载 |
| 同屏单位多掉帧 | 双半区合计同屏敌兵按 120 个设计；敌兵、伤害数字、墨迹全部对象池；战斗逻辑集中在一个 `BattleSim` 里批量更新，不给每个单位挂 `Update` |
| 汉字字体包体 | 战斗单位的字一律是图片（图集），不依赖运行时字体；UI 文本用裁剪过字集的字体 |
| iOS 内存 | 图集按章节拆分，切章卸载；纹理 ASTC 压缩 |

**退出条件**：P0 结束时在一台千元安卓机上实测，冷启动到可操作 ≤ 6 秒、战斗满屏 ≥ 50 帧。达不到就评估换 Cocos。

## 12. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| **换皮侵权** | 国内已有「换皮」判例（如《太极熊猫》诉《花千骨》），法院认定**游戏规则的具体表达**（系统组合、界面布局、数值、文字）整体高度相似时构成侵权 | 规则层（合成 + 塔防 + 组字）是品类通用框架，原作自身也源自《Random Dice》；但**美术、UI 布局、文案、数值表、关卡地形、道具名称与效果全部原创**；立项后请法务过一遍对照表；不使用原作任何截图、素材做买量 |
| **纯换皮弱于原作** | 《悟空与唐僧》同框架，表现不及前作 | 必须上线 §5.3–5.7 的水浒原生爽点（同姓抢字、名场面克制、及时雨、隐藏好汉），P1 盲测「像不像换皮」 |
| 品类窗口期 | 文字塔防 3 个月内已从单品变品类，跟进者会越来越多 | 总周期压到 10 周可上线（§14）；P0 两周验证不过就停 |
| 凑不齐名字的挫败 | 原作玩家吐槽「非洲体质，单字一堆凑不齐」 | 每关好汉字池收窄 + 保底 + 同姓抢字让单字更容易有用 |
| 对手 AI 被识破 | 玩家觉得被骗 | 明示「对手阵容来自玩家」，不伪装实时真人 |
| 审核 | 好汉对抗官兵，有「反官府」解读风险 | 敌方以原著具名反派和「贪官恶霸爪牙」为主，不出现「朝廷」「皇帝」字样；止于大名府，不做招安、征方腊；暴力表现全部用墨迹，无血；AI 生成内容按规定标识 |
| 字体版权 | 用了未授权书法字体 | 只用开源可商用字体或美术手绘 |
| 启动慢 | 团结首包 | §11.2 对策 + P0 实测退出条件 |

## 13. 设计审视清单（必过）

新增或改动任何玩法、数值、UI、商业化前逐条回答。任一条为「否」且无法修正，就不做或降权。

1. **规则不偏**：核心循环仍和原作一致吗？有没有加入让原作玩家需要重新学习的新操作？
2. **爽点不弱**：§3.5 的 S1–S8，这个改动削弱了哪一条？有没有补回来？
3. **每次聚义都是赌**：改完后玩家点聚义还会紧张吗？
4. **格子永远不够**：有没有让空间变得宽松、取舍消失？
5. **好汉有质变**：激活前后强度跳档还明显吗？
6. **是水浒不是换皮**：这个设计离开水浒还成立吗？如果成立，想想能不能更水浒。
7. **不撞原作表达**：美术、UI、文案、数值有没有和原作一眼雷同？
8. **广告预算**：核心流程广告点仍 ≤ 2？有没有「不看广告打不过」？
9. **审核安全**：有没有血腥、反朝廷、AI 内容未标识？
10. **性能预算**：同屏单位、首包、内存还在 §11 的红线内吗？

## 14. 开发阶段

总周期约 10 周到可上线。每阶段有退出条件，达不到不开下一阶段。

### P0 核心验证（2 周）

- 灰盒：单张地图、上下对称 1V1（对手为简单 AI）、4 个基础兵种 + 合成、聚义递增、山寨 5 格、4 名两字好汉（武松、林冲、李逵、花荣）+ 1 组同姓抢字（张顺 / 张清）、宋江 3 颗心 + 及时雨、1 个 Boss。
- 字用纯文本方块占位，不做美术。
- 千元安卓机实测启动与帧率。
- **退出条件**：5 名玩过《赵云与阿斗》的人里，至少 4 人认为「手感不输原作」，且至少 3 人主动提到同姓抢字或及时雨；启动与帧率达 §11.2 标准。

### P1 垂直切片（4 周）

- 第 1–3 章（清风寨、江州法场、白龙庙），16 名好汉，2 组羁绊，3 个 Boss + 克星演出。
- 正式美术：基础兵种动画、好汉金字、3 张地图、水格。
- 局外：体力、座次、结算、十字坡酒店（6 种道具）、好汉谱。
- 广告 2 个核心点 + 2 个功能点；埋点。
