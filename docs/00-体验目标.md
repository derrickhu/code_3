# 不对劲 · 体验目标（设计北极星）

> **本文件优先于一切玩法、数值、系统、商业化文档。**  
> 后续任何设计、改需求、加系统，都必须先用本文「审视清单」过一遍；通不过则改方案或砍掉，而不是改体验目标去迁就功能。

品类：单局现场揭状 · 多解改写  
平台：微信 / 抖音 / TapTap 小游戏　变现：首版纯 IAA；IAP 只预留结构，待版号后再开（见 §5.2）  
工作名：不对劲　正式名未定，不在切片阶段起营销名

## 0. 先承认：上一版和找茬没有核心区别

找茬的识别符不是「两张图」，是玩家每一步在干什么：

| 找茬每一步 | 上一版我们在干什么 |
|---|---|
| 搜：东西藏着 | 仍要在图里找那一处 |
| 找：有标准答案 | 仍是 1 处主破绽，对了才过 |
| 齐：找齐 N 处 | 我们改成了 1 处，但动作还是「找对」 |
| 难度 = 眼力 | 点完翻面只是奖励动画 |

换壳救不了幻想。code_1 换过长路、短距、棋盘，失败条件还写着漏怪，第一眼永远是塔防。  
**上一版的「一张图 + 点完翻面」救不了找茬。** 和找茬的差必须写在玩家手指上，不能写在演出上。

市场仍借同一条单位：眼睛点一下就成立（《一找一个准》畅玩第 5，微信大会点名素材依赖类）。  
**借「看一下就成立」，不借「搜、找、齐」。**

---

## 0.1 和找茬的核心区别（必须能指着规则说）

| | 找茬 | 本品类 |
|---|---|---|
| **动词** | 找到 | **揭**。我用这一处当证据，把现场写成另一种口气 |
| **难度** | 藏得深、看不清 | **不藏。** 每一样都认得出来。难的是揭哪一层 |
| **答案** | 有且仅有一套标准差异 | **一场 ≥ 2 处能揭，揭哪处现场变成哪一种** |
| **点错** | 没点中隐藏点 | **告错状**：看着怪、其实告不成 |
| **过场** | 找齐 / 打勾 | 现场按你揭的那处改写，下一场点名你揭过的东西 |
| **赢的原因** | 眼力好、细心 | 我揭的是招牌，不是收银 |

**一句话**

> 找茬是把图画对。我们是选择现场哪一句谎话被揭开。

若一场只有一处能过，或物件要放大才能看见，本品类已经退回找茬。不要靠文案硬撑。

## 1. 基调

**一句话世界观**

> 现场同时有几处在撒谎。你揭哪一处，这件事就按哪一处被写死。

物件都不藏。玩家认的是「我告的是这一门状」，不认两张对比图、不认放大镜、不认线索编号。基调服务「十秒可懂」：人看见两处都说得通的不对劲，点其中一处，现场变成这一种，立刻知道自己在选，不是在搜。

| 项 | 定 |
|---|---|
| 玩家位置 | 揭状的人。不是找不同的人，不是寻宝的人，不是侦探升级的人 |
| 对手 | 已经摆好的现场：便利店、饭局、合影、摊位。几处都在撒谎，看你揭哪一层 |
| 画风 | 生活现场，大色块，物件一眼认得。一张图。不做左右对照，不做立绘英雄，不做棋盘 |
| 色系 | 现场用生活色；揭对用砖橙；告错用闷红。不要侦探黑金，不要推理阴沉 |
| 文案 | 短句、口语。胜利说「不对劲」，不说「找茬成功」；告错说「这告不成」，不说「错误」 |
| 音效 | 手指点上、物件翻面、现场口气变了。不要放大镜「叮」，不要侦探小提琴 |

**命名规则**：夸张归现场变化，文字只负责好笑和说清楚。不要「线索 1/2/3」，不要「侦探等级」。

**题材边界**：现代生活现场优先，和 code_2 的「改通知」错开——这边揭物件，那边组字。不要仙侠魔幻，不要刑侦血腥。

## 2. 主体验目标

**正式表述**

> 当熟悉生活现场的玩家在碎片时间开一局时，反复感到：**「我揭的是这一处，现场就变成这样」**——赢来自我选了哪一门状，而不是我眼力好、手速快或者肝得久。

**一句话**

> **我揭的是这一处。**

**玩家应脱口而出**

- 「揭招牌是加班，揭收银是走账」
- 「这个看着怪，告不成」
- 「下午那场是因为我上午揭了监控」
- 「换一处，口气就不一样」

**这句话的含义要落到三个可检验的点**

1. **本局独有**：同一张现场，换一处揭，改写不同；下一场因你揭过的那处而不一样。变化不是「又找了 5 处」。
2. **对象是具体的一处**：玩家能指着屏幕说「我揭的是这个，不是那个」。不是全场高亮，不是自动圈出。
3. **揭看得见**：揭完之后，物件、现场、口气同时变成这一种。不靠飘字「找茬 +1」。

**主体验的核心动词是「揭」。**  
点、点选都可以，但玩家心里完成的动作必须是「我揭开了这一层」，不是「我找到了」「我消了」「我对上了」。

## 3. 反目标（坚决避免）

玩家若经常感到以下任一，即体验目标失败：

| 反目标感受 | 典型诱因（设计上要挡） |
|---|---|
| **「这不就是找茬吗」** | 东西藏着；只有一处能过；赢靠眼力；点完只打勾 |
| **「这不就是找不同吗」** | 左右两张图；「还剩 N 处」；像素差、少颗扣子 |
| **「这不就是寻物吗」** | 清单：「找出西瓜」；放大镜地毯搜 |
| **「这不就是文字游戏吗」** | 破绽只写在句子里，物件不参与；和 code_2 抢「改那句话」 |
| 「点哪儿都一样」 | 两处能揭，改写却相同；没有「告不成」的陷阱 |
| 「打不过就是没刷到简单图」 | 关卡黑箱、把物件缩小当难度 |
| 「系统太多，不知道该干啥」 | 多养成线、侦探等级、图鉴收集主线 |

**头号风险是第一条。**  
两图对比只是找茬的皮。真正的识别符是「搜 + 唯一答案」。砍掉两张图但保留唯一答案，第一眼仍是找茬。

**告错必须能罚，而且罚得明白。**  
现场里要有「看着怪、其实告不成」的物件。点它不是「没找着」，是「这门状告不成」，并给出比「错误」更清楚的路径：换一处揭。

## 4. 玩法骨架（体验的实现方式）

| 层级 | 内容 | 说明 |
|---|---|---|
| **主** | 从几处都不藏的物件里，选一处揭开 | 「揭哪一处」就是主体验的动作，不能省成自动圈出，也不能收成唯一答案 |
| **强辅** | 揭完之后的现场改写 | 物件翻面，口气变成这一种。让「我揭的是这个」看得见 |
| **弱辅** | 本局主题现场 + 案底 | 你揭过的物件，下一场会点名。给「本局独有」落地，不做成图鉴 |

**硬性骨架**

| 项 | 值 | 为什么 |
|---|---|---|
| **失败条件** | 告错次数用尽，或本场超时 | 写成「没找齐 / 没找着」，第一眼永远是找茬 |
| **胜利条件** | 本局现场全部按你揭的那条线走完 | 赢要能指回「我揭的是哪几处」 |
| **同时可见的可点物件** | ≤ 8 个，且全部一眼认得 | 再多就变成搜。藏进角落、缩小、要放大 = 找茬 |
| **一场能揭的处数** | **≥ 2，改写必须不同** | 只有 1 处能过，就是找茬。两处改写相同，就是换皮打勾 |
| **陷阱** | 每场 ≥ 1 个「看着怪、告不成」 | 没有它，玩家学不会「揭」，只会学「点怪的」 |
| **两图对比 / 寻物清单 / 放大镜 / 像素差** | **不做** | 找茬家族的识别符 |
| **搜索难度** | **不做** | 难度只来自「揭哪一层」和「下一场吃案底」 |
| **自动战斗 / 自走** | **不做** | 主操作必须是揭 |

**聪明感的关键时刻**：两处都说得通，揭招牌是加班，揭收银是走账；你选了招牌，下午那场变成「谁让店加班的」。  
若玩家卡关后第一反应是「再来一局碰简单图」而不是「换一处揭」，主目标已偏。

**一条现场的合格标准（切片就要钉）**

```
scene:     便利店夜班
caption:   今日休息
expose_a:  招牌「今日休息」 → 今日加班 / 老板回来了
expose_b:  收银员袖口的现金 → 店关了，他在走账
trap:      过期面包 → 这告不成（过期和关门说得通）
tone:      损、短、能当梗
```

- 招牌和袖口现金都必须一眼看得见，不能靠放大。
- 没玩过的人听完两种改写，能说出差别。听完要解释的，重写。
- 两种 `expose` 的下一句口气必须不同。相同则重写。
- 玩家点的是物件，不是一段要读完的字。字可以写在招牌上。

**案底（本局独有的最小落地）**

你揭过的物件作为「今天的案底」留下，后面的现场会点名。  
揭了招牌 → 下一场可能是「谁把休息改成加班的」。  
揭了收银 → 下一场可能是「账对不上」。  
案底只在本局有效。没有的揭法走默认下一场。同一局最多点名 2 次，避免写成连续剧。

## 5. 人群与游玩情境

以下每条都是硬约束，不是建议。来源是 2026 小游戏大盘、微信 IAA 用户结构、三端分发差异，以及仓库里已有产品的分工。

### 5.0 人群

| 层 | 是谁 | 他们要什么 | 他们不要什么 |
|---|---|---|---|
| **核心** | 18–35 岁，城市，微信 IAA 盘里的人（该盘 70% 只玩休闲广告游戏；女性约 60%） | 「我揭的是这个」的聪明感，一句能转发的现场 | 两图找不同、放大镜找扣子、唯一答案眼力题 |
| **泛** | 25–40 岁轻度玩家，被直玩素材点进来；含抖音信息流和 TapTap 点开即玩 | 认得生活现场就能玩；看见两处都能点；看广告换续揭说得通 | 读技能、认英雄、左右对照图、地毯搜 |
| **不做** | 找茬题海党（当设计目标）、重度 IAP 养成、动作手感党、看英雄打架党、温馨经营党 | — | 已分别由畅玩找茬模板 / xiaochu / 跑酷筛掉 / code_1 与 srpg / huahua 覆盖 |

**核心用户的工作，不是人口统计。**

> 我只有两到四分钟。我要做成一件事：一张现场几处都在撒谎，我揭开其中一层。做成了，我知道是哪一件东西把后面写成这样的。

他们可能玩过羊了个羊、找茬、沙雕小游戏，未必玩过战棋或转珠。文化门槛必须低到：认得便利店和饭桌就能玩；不认得某个梗，也不妨碍揭另一处。

**和已有 code 的人群关系**：同一批 IAA 用户，月人均在玩 7.5 款。

| 工程 | 时间袋 | 动词 | 互相关系 |
|---|---|---|---|
| code_1 | 7–10 分钟战斗袋 | 装 | 不互相替代 |
| code_2 | 3–6 分钟组对袋 | 对 | 不互相替代 |
| **code_3** | **2–4 分钟一眼袋** | **揭** | 占更短的缝：等人、通勤、上个厕所 |

可以轮着玩。任何「加点组字 / 加点改装」的提案，回对应工程，不要接到本品类。

**三端同一批人，进法不同**

| 端 | 他们怎么进来 | 设计要保住的 |
|---|---|---|
| 微信 | 畅玩 / 搜一搜 / 会话分享，自然量优先 | 前 10 秒看见两处都能揭，点一处现场变成这一种 |
| 抖音 | 直玩素材、信息流买量 | 素材里必须看见「揭 A 是加班、揭 B 是走账」，不是「找到了」 |
| TapTap | 点开即玩、评论区较真 | 不要做成两图找不同的第 N 款；结算要写得回「我揭的是××」 |

### 5.1 游玩情境

| 约束 | 值 | 为什么 |
|---|---|---|
| 单局长度 | 2–4 分钟 | 比 code_2 更短的时间袋；碎片缝里能打完 |
| 一局场数 | 4–6 个现场 | 太少没有案底；太多变成找茬题海 |
| **十秒可懂** | 前 10 秒内必须看到一次「两处都能点 → 揭其中一处 → 现场变成这一种」 | 只看见「点对了打勾」，就是找茬。开局不允许有选关、图鉴、侦探档案 |
| **核心流程广告点 ≤ 2** | 只放「结算双倍」与「告错续一次 / 加时」 | 大盘：核心单流程广告点少于 3 个时新进次留约 23%，3–5 个掉到 17%。xiaochu2 排了 4 个，正落在差的那一档 |
| **中位数 IPU ≥ 6** | 看中位数不看平均 | xiaochu2 平均 7.9 是两名重度用户抬起来的，一个活跃玩家真实值只有 0.57 |
| 不接插屏 | 切片与首版都不接 | 插屏与激励视频抢同一频控窗口，激励视频 eCPM 更高 |
| 首版无内购 | 不开 IAP，按 §5.2 预留结构 | 无版号。任何「靠付费深度才能过」的设计在无版号期只会劝退 |
| 平台 | 微信优先，抖音 / TapTap 同步打同一套内容 | IAA 自然量先跑微信；抖音最优分成绑买量；Tap 零分成、独立运行时，首版游客 |
| 场合 | 单人 | 实时 PVP 匹配会拖死十秒可懂和短回收 |
| 题材 | 现代生活现场优先 | 2026 上半年现代题材在投近 7000 款，审核风险低于仙侠魔幻；也避开刑侦 |

### 5.2 IAP 预留原则

首版纯 IAA，但**结构从第一天就要留**。xiaochu2 的教训：免费经济先按「完全没有付费」校准，再塞付费，只能打折硬挤。

| 档位 | 内容 | 为什么归在这一档 |
|---|---|---|
| **现在就必须定** | ① 资源发放走同一入口，带 `source`（`free` / `ad` / `iap` / `quest`）<br>② 账本以服务端为权威，订单幂等接口形状先留<br>③ 定义「一次广告 = 多少资源」<br>④ 埋点按 `source` 分账 | 事后改等于重做存档信任与数值校准。**只做接口形状，不接支付 SDK** |
| **可以后加** | 商店 UI、SKU、定价、月卡、支付 SDK、审核资质 | 叶子功能，不动核心循环 |
| **即便开了 IAP 也不做** | 卖「揭示哪一处能揭」或提示抽卡；直售胜率；付费墙式难度 | 揭的快感来自「我选了这一层」。答案能买，揭状就变成付费进度条 |

**日后 IAP 优先卖现场皮肤、贴纸框、主题滤镜的 cosmetic。** 不卖胜率。去广告要谨慎：它直接吃 IAA。

## 6. 设计审视清单（必过）

新增或改动玩法 / 数值 / UI / 商业化前，逐条回答。任一条为「否」且无法修正 → **不做或降权**。

1. **揭能写成不同现场**：这一处和另一处能揭，改写是否明显不同？（打勾、+1、两种揭同一句，都不算）
2. **不藏**：所有能点的物件是否一眼认得？是否出现了缩小、边角、必须放大才能看见？若是，直接砍。
3. **不是唯一答案**：这一场是否至少两处能揭？只有一处能过，就是找茬，直接砍。
4. **告错有差异**：是否有「看着怪、告不成」的物件？点它是否和揭开明显不同？
5. **不像找茬家族**：是否出现了左右两张图、「还剩 N 处」、像素差、清单、放大镜？若是，直接砍。
6. **不像组字**：破绽是否主要写在句子里、物件只是背景？若是，回 code_2。
7. **卡关路径**：玩家卡住时，游戏是否把「换一处揭」提示为比「再来一局碰简单图」更清晰的路径？
8. **胜利归因**：结算是否让人感到「我揭的是××」，而不是只感到「这局眼力好」？
9. **十秒可懂**：改动后，前 10 秒是否仍能让没玩过的人看到「两处都能点，点一处变成这一种」？
10. **广告点预算**：核心流程广告点是否仍 ≤ 2？
11. **变现不成为前置**：是否制造「不看广告就过不去」或「不付费就过不去」？涉及 IAP 时追加：这件商品若上线，是否会让不付费玩家的现有体验变差？会则不做。
12. **系统负担**：是否增加了让玩家忘记「揭」的干扰目标？

## 7. 加 / 慎 / 砍（速查）

| 倾向 | 例子 |
|---|---|
| **加** | 一场两处以上能揭且改写不同、揭完现场立刻翻成这一种、陷阱「这告不成」、案底点名、结算写出「本局揭了哪些」、分享语带两种揭法对比 |
| **慎加** | 局外成长、第三处以上的能揭（先验两处够不够）、实时对手、超过 8 个可点物件 |
| **砍 / 降权** | 唯一正确答案；搜索难度（缩小 / 边角 / 放大镜）；两图对比；「还剩 N 处」；寻物清单；像素差；侦探等级与图鉴主循环；漏怪与底线血；二合升级；自动战斗；转珠；棋盘；提示抽卡与付费胜率；前置选关页；核心流程第三个广告点；插屏 |

## 8. 验收标准（体验是否达标）

| 维度 | 标准 | 测法 |
|---|---|---|
| **体验** | 玩家能说出本局是靠「揭了哪几处」走成这样的 | 试玩后问「刚才怎么赢的」。答案指向具体物件且说得出「不是另一处」即通过；答「眼力」或「找到了」即不通过 |
| **多解** | 同一场至少有人揭过不同的一处 | 两人打同一场，改写不同。从未出现第二种揭法，则仍是找茬 |
| **陷阱** | 玩家至少主动避开或事后承认过一次「这告不成」 | 从未碰到陷阱则「揭」没有被教出来 |
| **不像邻品** | 没玩过的人看完前 10 秒，不会说这是找茬、找不同、寻物、文字组对 | 录前 10 秒盲测。若说找茬，先查是不是又做成了唯一答案或搜索题 |
| **商业** | 中位数 IPU ≥ 6，且次留不低于改动前 | 埋点看中位数，同时看「开战 ≥20 场的人里 IPU < 2 的占比」 |
| **节奏** | 单局 2–4 分钟，卡关来自「告错」而不是「找不着」占八成 | 切片阶段先用 4 个现场验「两种揭法」密度 |

最可能挂掉的是**多解**和**不像邻品**。挂了就不是加时限能救的。不要改体验目标去迁就「先做一处能过的找茬再加多解」——先做唯一答案，产品会停在找茬。
