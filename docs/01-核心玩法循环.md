# 不对劲 · 核心玩法循环

> **体验北极星**（更高优先级）：见 [00-体验目标.md](./00-体验目标.md)  
> 主体验 = **我揭的是这一处。**  
> 本文所有循环与规则都是实现该体验的手段；新增或改动前先过体验目标的「设计审视清单」。

---

## 1. 核心循环

```
一张现场摊开（物件都不藏） → 点一处揭开
        ↑                         ↓
  下一场点名案底          揭开：现场按这一处改写
                          告错：这告不成，扣一次
```

单局自闭环。局外首版只记「揭过的处数」，不做第二条养成线。

**「揭哪一处」是独立的一步，不自动圈出。**  
系统可以同时提醒两处都能揭，但不能替玩家揭。省掉这一步，或收成唯一答案，游戏就退回找茬。

## 2. 一张现场，不是两张图

场上只有三种东西：口气牌、可揭物件、你已经揭过的案底。

| 为什么这样 | 说明 |
|---|---|
| 口气牌是局面，不是关卡名 | 玩家改的是现场变成哪一种，不是找齐 N 处 |
| 物件是单位 | 每个物件一眼认得、点得着。不超过 8 个 |
| 揭是一次行动的结果 | 点下去，现场按这一处写成另一种口气 |
| 不需要对照图 | 左右两张是找不同的识别符 |

**揭哪一层是这条循环的全部策略厚度。**  
揭招牌是加班，揭收银是走账。没有第三条隐藏规则。玩家学的就是：对着这张现场，选一门状。

## 3. 失败条件：告错，不是没找着

**没有「还剩 N 处」，没有放大镜，没有漏怪。**

- 告错次数用尽 → 判负
- 本场超时还没揭 → 判负
- 本局现场全部按你揭的那条线走完 → 通关

搜索、藏、找齐不产生任何胜负。回归测试必须钉死：状态机里不存在 `leftover` / `remaining` / `lane` / `leak`。

## 4. 揭：主体验的载体

每一次行动点一个物件。结果只有三类：

| 结果 | 含义 | 玩家应感到 |
|---|---|---|
| `expose` | 揭开了，现场变成这一种 | 「我揭的是这一处」 |
| `trap` | 看着怪，这门状告不成 | 「换一处揭」 |
| `idle` | 点到现场空地 | 不扣，不当一次揭 |

每条 `expose` 必须能回答一句：**它让现场从什么变成了什么，且和另一处能揭的不同。**  
只打勾、不改口气的揭一律不做。

切片的典型揭：

| 揭 | 结果 | 现场变成 |
|---|---|---|
| 招牌「今日休息」 | expose | 今日加班 / 老板回来了 |
| 收银袖口现金 | expose | 店关了，他在走账 |
| 过期面包 | trap | 这告不成。过期和关门说得通 |

两条硬约束：

- **一场至少两处能揭，改写必须不同。** 只有一处能过，就是找茬。
- **物件不藏。** 最短边小于 88 设计像素，或必须放大才看见，就是找茬。

## 5. 案底让下一场不一样

你揭过的物件留下 `record`。后面的现场会点名，或直接走另一张图。

揭了招牌 → 下一场是「谁让店加班」。  
揭了收银 → 下一场是「账对不上」。

案底只在本局有效。这是「本局独有」的最小落地，不做养成。

## 6. 单局节奏

| 段 | 内容 | 意图 |
|---|---|---|
| 第 1 场 | 便利店。招牌和袖口都一眼认得 | 十秒内打出第一次「揭」，且看见两种揭法 |
| 第 2 场 | 吃案底。加班线或走账线 | 验「下一场因你揭过的那处而不同」 |
| 第 3 场 | 饭局。买单和 AA 都能揭 | 换皮，动词仍是揭 |
| 第 4 场 | 收工。结算前再揭一次 | 结算能指回「本局揭了哪几处」 |

切片 4 场，大约 2–4 分钟。第一场同时脉动两处能揭的物件，不指定唯一答案。

告错机会：全局限 3 次。太少会变成不敢点；太多会让「揭」不再值钱。

## 7. 可读性

主快感是看见现场被自己写成这一种。**看不懂那次揭，就等于没做。**

| 信息 | 表现 | 为什么排这个优先级 |
|---|---|---|
| **揭看得见** | 物件翻面，口气牌立刻换成这一种 | 主体验第三个可检验点 |
| 告错 | 物件晃一下，提示「这告不成」 | 卡关路径必须指向换一处，不是重开 |
| 案底 | 底栏列出你揭过的物件 | 「本局独有」当场能看见 |
| 还能错几次 | 三枚印，砸错一枚就糊掉 | 失败来自告错，不要做成血条 |
| 本场还剩多久 | 细线，不做成倒计时炸弹 UI | 超时是失败条件之一，但不能抢「揭」的戏 |
| 结算 | 列出本局揭了哪几处，一句「靠这几处」 | 体验验收第一条 |

明确不做：左右对照、放大镜、「还剩 N 处」、像素差、寻物清单、侦探等级。

## 8. 十秒开场

| 时间 | 画面 |
|---|---|
| 0.0s | 直接在便利店。口气牌写着「今日休息」 |
| 0.6s | 招牌和收银袖口同时轻轻脉动。一句「两处都能揭，揭哪处就不一样」 |
| 第一次揭 | 口气牌换句，现场翻成这一种。主体验完成一次 |

验收：录前 10 秒给没玩过的人看。说不出「点一处，现场变成这一种」，就要改开场；若他说找茬 / 找不同 / 寻物，回去查第 3 节和第 4 节。

## 10. 埋点事件表

| 事件 | 关键字段 | 用途 |
|---|---|---|
| `run_start` | seed, theme | 局数 |
| `run_end` | cleared, duration_ms, exposes, traps | 体验验收 |
| `expose_try` | prop_id, kind, scene_id | **验证取舍与多解** |
| `scene_rewrite` | scene_id, from, to, record | 主体验是否发生 |

必看：同一场 `expose` 的 `prop_id` 分布 —— 某一处超过 85%，说明另一种揭法没有被看见。
